# 컴퓨터공학 자습 로드맵

컴퓨터공학과 학생을 위한 인터랙티브 자습 로드맵. 전공 **10개 분야 · 50개 주제**를 방사형 마인드맵으로 보여 주고, 주제를 누르면 *무엇을 할 수 있으면 끝인지*까지 나온다.

빌드 도구 없음. 순수 HTML · CSS · JavaScript. 그대로 GitHub Pages에 올리면 동작한다.

## 구조

```
index.html                 마크업 + 스크립트 로드 순서
manifest.webmanifest       PWA 설치 정보
sw.js                      서비스 워커 (네트워크 우선, 오프라인은 캐시)
icons/                     아이콘 (tools/make-icons.js 로 생성)
css/style.css
js/
  data.js                  코어 — LEVELS, ROADMAP, defineDomain()
  domains/01~10.js         분야별 내용 (로드 순서 = 마인드맵 배치 순서)
  paths.js                 추천 경로 4갈래 (단계 → 주제 id)
  mindmap.js               SVG 방사형 배치, 팬/줌, 충돌 회피
  app.js                   상세 패널, 검색, 난이도 필터, 추천 경로, 해시 라우팅
  pwa.js                   설치 버튼, 서비스 워커 등록
tools/
  make-icons.js            아이콘 PNG 생성 (외부 의존 없음)
  serve.js                 로컬 미리보기 서버 (배포에는 불필요)
```

## 주제 한 건의 형태

```js
{
  id, name, level(1~3),
  check,     // 이걸 답할 수 있으면 안다 — 자가진단 한 줄
  tag,       // 한 줄 설명
  why,       // 왜 배우나
  goal,      // 무엇을 할 수 있으면 끝인가
  deliver[], // 완료 판정 체크리스트
  focus[],   // { t: 중점 포인트, d: 왜 그런지 }
  concepts[],// { t: 같이 볼 개념, d: 한 줄 정의 }
  stack[], steps[], next[], note?
}
```

난이도는 `1` 입문 · `2` 중급 · `3` 심화 3단계다.
각 분야에서 `lead: true` 인 주제 하나가 분야 노드의 얼굴이 되어 첫 화면에 노출된다.

## 추천 경로

50개를 한꺼번에 보면 시작이 안 되므로, 오른쪽 위 **추천 경로** 버튼에 목표별 순서를 넣어 뒀다.

| 경로 | 대상 | 규모 |
|------|------|------|
| 전공 정석 코스 | 진로 미정, 커리큘럼 순서대로 | 8단계 · 50주제 |
| 백엔드 · 서버 개발 | 서비스 백엔드/인프라 지망 | 5단계 · 20주제 |
| 인공지능 · 데이터 | 머신러닝·데이터 분석 지망 | 5단계 · 17주제 |
| 취업 준비 단기 코스 | 취업이 1년 안쪽 | 5단계 · 21주제 |

경로를 고르면 패널에 단계별 트랙이 세로로 펼쳐지고, 마인드맵에는 해당 주제에만 **단계 번호 배지**가 붙는다 (`마인드맵에 표시` / `표시 끄기`).

경로 데이터는 `js/paths.js` 한 파일이다. 단계를 추가하려면 `stages[]` 에 `{ label, sub, goal, items[] }` 를 넣으면 된다. `items` 의 주제 id 가 실재하지 않으면 진입 시 콘솔에 경고가 찍힌다.

## 조작

- 분야 노드 클릭 → 상세 패널 + 같은 분야 주제 펼침, 한 번 더 클릭하면 접힘
- 중심 노드 클릭 → 전체 펼치기 / 접기
- 오른쪽 위 `추천 경로` → 목표별 순서를 단계 트랙으로
- `/` 검색, `ESC` 패널 닫기, 난이도 칩으로 필터
- 드래그로 이동, 휠로 확대, `⤢` 로 화면 맞춤
- 주제를 열면 주소에 `#주제id` 가 붙어 그대로 공유 가능

## 로컬 실행

```bash
node tools/serve.js
```

`http://localhost:4173` 에서 열린다. 서비스 워커는 `file://` 에서 등록되지 않으므로 파일을 직접 여는 대신 이 서버를 쓴다.

아이콘을 다시 만들려면:

```bash
node tools/make-icons.js
```

## 배포

GitHub Pages 에 그대로 올린다 (Settings > Pages > 브랜치 선택).

내용을 고친 뒤에는 `index.html` 의 `?v=N` 과 `sw.js` 의 `VERSION` 을 **함께** 올린다. 둘 중 하나만 올리면 캐시에 남은 옛 파일이 섞여 나온다.

## 내용 추가하기

새 분야는 `js/domains/` 에 파일을 만들고 `defineDomain({...})` 을 호출한 뒤 `index.html` 의 스크립트 목록에 순서에 맞게 추가한다. 배치 순서는 로드 순서를 그대로 따른다.
